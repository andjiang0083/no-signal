# v0.0.15 世界大满贯 + v0.0.16 声音大满贯 — 实施计划

> 日期：2026-09-07 · 项目：no-signal（ESP32-S3 M5StickS3）· 基线：v0.0.14（呼吸层里程碑已提交）
> 格式：每任务含 objective / files / steps / verification / commit。嵌入式项目无单测框架，验证 = 编译 + 真机 harness 截图目检，最终 prod + merge_bin。

**Goal**：把节目池从"自然风光"扩成"世界盲盒"（自然/文明/神话/科幻四大类 36 剪影 + 天体/台标/稀有扩充 + 外星灯牌），随后给节目配上独立声学轴（盖革计数器系统为核心）。

**版本**：v0.0.15 = 纯画面（不改音响）；v0.0.16 = 纯声音。两版各自可独立真机验证、独立发布。

## 风险与对策

1. **主体画法一次性量大** → 按批次（T4-T7）逐个真机目检后才进下一批，不回炉
2. **tone() 与 playRaw 叠加不稳定** → T12 先花一个任务验证基底，不行则改用纯 playRaw 样本混音（预混合 16ms × N 或降密度）
3. **科幻主体太多导致"神秘感"稀释** → 声学轴偏置 + 稀有事件分级兜底（科幻仍是最响最怪的类别）
4. **版本号**：v0.0.15 / v0.0.16 连续小 patch，不跳号（惯例）
