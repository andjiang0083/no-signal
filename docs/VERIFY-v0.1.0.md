## 1. dev 版注入开关（真机验证用，prod 无此代码）

`POST /hrns/data` 单键注入：

| 键 | 作用 |
|---|---|
| `nosig` | 原故障场景（回归基线） |
| `snow=N` / `warp=N` / `text=N` | 固定雪花变体 / 扭曲 / 文字变体（帧内确定性复现） |
| `glitch=N` | 固定招牌乱码位（字模与索引验证） |
| `info=N` / `ch=N` | 固定台标款式 / 频道号（呼号 = `CALLS[ch%6]`） |
| `snd=N` | 固定声学档位（P0-1 逐档试听） |
| `marker=N` | **几何探针**：扭曲前在行 0/6/12… 的 `x%7==0` 画白点 → 白点相位可测出撕裂位移量 |

> 探针与注入代码全部在 `#ifndef PRODUCTION_BUILD` 内，发布版零占用；保留在 dev 方便下次走查。

## 2. 数值判据（为什么这些数字能当证据）

- **BMP 帧缓冲**（240×135 RGB565，54 字节头）：每次抓帧硬校验 `len==64854`，越界/截断立即暴露。
- **字模**：从源码解析 `FONT57` + `glyphIdx`，用同一位图在屏上按「ink 应亮 / 格底应黑」**双向**比对；反事实＝把缺失字母按旧行为跳过再算一遍（形成对照组）。
- **撕裂位移**：雪花的统计特性对水平位移不敏感（位移不可测），因此用探针条纹把位移变成几何量；白点间距 7px 与位移 20/12 互质 → 相位唯一确定位移模 7，环绕点位置再锁定绝对值。
- **呼吸**：连拍 16 帧的整帧平均亮度序列 —— 基线极差 0.5 是噪声底，3.0 且单调起伏即正弦。
- **负片**：琥珀调色板满足 `R≥G≥B`，其逐通道补色必然满足 `R≤G≤B`；通道错位（旧 bug）会破坏该序关系 → 用全帧占比当判别式。
